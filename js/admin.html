Como isso funciona: este site não tem servidor/banco de dados, então tudo que você editar aqui fica salvo só neste navegador. Para as mudanças aparecerem para todo mundo que visita o site, use o botão "Baixar catálogo atualizado" no fim da página e peça para quem cuida da hospedagem substituir o arquivo js/products-data.js pelo que foi baixado.
Produtos vendidos por peso: se a unidade de um produto for kg, o carrinho e a mensagem do WhatsApp tratam ele como "a pesar" — o cliente vê o preço por quilo, mas o valor final e o total do pedido só são fechados por vocês depois da pesagem na loja. Qualquer outra unidade (ou nenhuma) é somada normalmente no total.

Criar conta de administrador

Esta é a primeira vez que o painel é acessado neste navegador. Crie o usuário e a senha do administrador.

⚠️ Como o login é feito só pelo navegador (sem servidor), qualquer pessoa com acesso técnico a este computador pode contornar essa senha. Não é uma segurança de nível bancário — é um controle de acesso simples para afastar curiosos.
